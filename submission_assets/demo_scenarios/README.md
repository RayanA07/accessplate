# Demo Scenarios

Use this folder for the short, reproducible stories shown in a DEBUT demo or pitch deck.

Each scenario should include:

- user profile
- pantry state
- transportation and travel limit
- benefit-program settings
- realistic food-source availability
- expected first stop
- expected buy order
- expected backup plan

Start from `accessplate_demo_scenarios.md` and copy `template_demo_scenario.md` for each new case.

For the live presentation sequence, use `demo_run_of_show.md`.
