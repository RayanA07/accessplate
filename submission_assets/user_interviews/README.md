# User Interviews

Use this folder for structured low-resource user testing notes.

Suggested files:

- `interview_script.md`
- `participant_log.md`
- `task_outcomes.md`
- `plain_language_failures.md`

Key outcomes to capture:

- Could the user tell where to go first?
- Could the user tell what to use from home first?
- Could the user tell what to buy first and what to skip?
- Did SNAP/WIC wording make sense?
- Did Spanish/plain-language mode reduce confusion?

Use `template_interview_script.md` for the interview flow and duplicate it into participant-specific notes as needed.

Use `accessplate_user_test_packet.md` for the recommended scenario order, scoring rubric, and success thresholds.
