# AccessPlate User Test Packet

Use this packet to run lightweight, scenario-based user sessions with people who resemble the target population for the NIMHD low-resource setting prize.

## Primary goals

Measure whether users can quickly understand:

- where to go first
- what to use from home first
- what to buy first
- what to skip if money is tight
- what the backup is

## Suggested sample

Aim for `6 to 10` participants across these categories:

- limited transportation or no car access
- SNAP or WIC use
- pantry or dollar-store reliance
- microwave-only or no-cook setup
- English and Spanish speakers

## Materials checklist

- test phone with the app installed
- one printed scenario sheet per session
- consent form handled outside this repo if needed
- note-taking sheet or local notes file
- timer

## Task flow

### Task 1: problem understanding

Ask:

- "What do you think this app is trying to help with?"

Success:

- participant says some version of food access, affordable meals, reachable options, or what to get today

### Task 2: first stop

Give a scenario and ask:

- "Where would this app tell you to go first?"

Success:

- participant can identify the first stop without opening many screens

### Task 3: use-from-home understanding

Ask:

- "What does the app want this person to use from home first?"

Success:

- participant identifies pantry use correctly

### Task 4: buy order

Ask:

- "What should they buy first?"
- "What can they skip first if money gets tight?"

Success:

- participant can name the first buy and one lower-priority item

### Task 5: backup understanding

Ask:

- "If the first option does not work, what is the backup?"

Success:

- participant identifies a backup source or backup item

### Task 6: language and clarity

If applicable:

- switch to Spanish or plain-language mode
- repeat the first-stop and buy-order tasks

Success:

- participant still finds the key action path

## Scoring rubric

Use `0 to 2` per item:

- `0`: could not identify it
- `1`: found it with help or after confusion
- `2`: found it quickly and correctly

Score these items:

- app purpose
- first stop
- use from home
- buy first
- skip first
- backup
- benefits wording clarity
- overall realism

## Success thresholds

Strong early evidence looks like:

- average score of `1.5+` on first stop
- average score of `1.5+` on buy first
- most participants can explain the backup
- Spanish/plain-language users do not perform worse than English users on the key action tasks

## Debrief questions

- What part felt most useful?
- What part felt confusing?
- Did anything sound too technical?
- Did the app feel realistic for your day?
- What would make you trust it more?

## Output to save after each session

- participant code only
- scenario used
- scores
- confusion points
- quotes worth preserving
- specific copy or logic changes suggested

## Important caution

Do not over-interpret tiny sample sizes as validation of outcomes. Treat these sessions as usability and realism evidence, not clinical proof.
