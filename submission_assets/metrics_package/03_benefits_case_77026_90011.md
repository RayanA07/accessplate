# Metric Case 03: Benefits-Aware Decision Quality

- Scenario links:
  - `../demo_scenarios/03_snap_tight_budget_77026.md`
  - `../demo_scenarios/04_wic_grocery_vs_convenience_90011.md`
- Main question: does AccessPlate make benefit fit part of the decision, not just a label?

## Baseline assumption

- A generic recommender may rank foods without changing source choice or buy order for SNAP or WIC use.

## AccessPlate evidence to capture

- Whether `Likely SNAP-compatible` items move into `Buy first`
- Whether hot/prepared caution items move into `Skip first`
- Whether WIC grocery candidates outrank convenience options when appropriate
- Whether state-aware notes are visible when the model knows the state

## Strong result looks like

- Benefit fit changes both first stop and purchase order
- Explanations use precise benefit language instead of vague wording
- Backup options still remain realistic if the best source is not possible
