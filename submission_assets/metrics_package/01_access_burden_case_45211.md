# Metric Case 01: Access Burden Reduction

- Scenario link: `../demo_scenarios/01_emergency_no_cook_45211.md`
- Main question: does AccessPlate avoid an unrealistic grocery-first decision in an emergency?

## Baseline assumption

- A nutrition-first ranking might overvalue a grocery-only option even if the trip is longer and the user has no cooking setup.

## AccessPlate evidence to capture

- Time to identify first stop
- Chosen source type
- Travel burden difference between top pick and backup
- Whether the app kept the plan inside the no-cook constraint

## Strong result looks like

- First stop is convenience or dollar store
- Buy order is visible immediately
- Grocery-only options are demoted or explained as weaker backups
