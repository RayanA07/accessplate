# Metric Case 04: Low-Literacy and Bilingual Usability

- Scenario link: `../demo_scenarios/05_spanish_plain_language_60623.md`
- Main question: can a user still identify the first action quickly in Spanish/plain-language mode?

## Baseline assumption

- Decision support often becomes too technical or too English-heavy under stress.

## AccessPlate evidence to capture

- Time to identify `where to go first`
- Time to identify `what to use from home first`
- Time to identify `what to buy first`
- Participant confusion points in Spanish or plain-language mode

## Strong result looks like

- The user can name the first stop, buy order, and backup without opening multiple screens
- Explanation text stays short and understandable
- The same deterministic logic remains visible in Spanish
