# Metrics Package

Use this folder for compact evidence that the prototype is improving low-resource decisions, not just producing nice-looking recommendations.

Suggested contents:

- `time_to_decision.md`
  - compare how long it takes to choose a meal with and without AccessPlate
- `access_burden_examples.md`
  - show cases where the app avoids a harder grocery trip in favor of a realistic pantry, dollar-store, or convenience option
- `benefits_examples.md`
  - show buy-order differences for SNAP/WIC-focused runs
- `cost_examples.md`
  - compare a naive nutrition-first ranking against the access-first plan

For each metric example, capture:

- user profile
- pantry state
- source availability
- top pick
- first stop
- buy order
- backup
- why the access-first output is meaningfully better

Use `template_metric_case.md` for each example so the comparisons stay consistent.

Use `judging_matrix.md` to connect these cases back to significance, impact, innovation, and prototype strength.

Use `evidence_scorecard.md` to roll user-testing and scenario results into one summary sheet.
