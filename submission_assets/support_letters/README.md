# Support Letters

Store draft or final support letters here if the team decides to keep them in-repo.

Recommended sources:

- community organizations
- food pantry networks
- clinic or health-system partners
- faculty mentors
- local public-health collaborators

At minimum, track:

- source organization
- contact
- date requested
- date received
- whether the letter can be quoted publicly

Use `template_support_letter_outline.md` so requests stay consistent across organizations.

Use `support_letter_request_template.md` when sending the first outreach email or offering draft language.
