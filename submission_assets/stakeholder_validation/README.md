# Stakeholder Validation

Capture short notes from:

- food pantry operators
- community health workers
- safety-net clinic staff
- public-health or nutrition faculty
- SNAP/WIC-adjacent service providers

For each conversation, record:

- who the stakeholder was
- what scenario they reacted to
- what they said was realistic
- what they said was unrealistic
- what product or copy changes were made afterward

Use `template_feedback_note.md` so each conversation records the same details.

Use `accessplate_partner_review_packet.md` to run the session consistently.
