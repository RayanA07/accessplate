# Submission Assets

This folder is for NIH NIBIB DEBUT 2026 / NIMHD submission support material that should live near the prototype, but not inside the shipping app flow.

Use this folder as the working package for the evidence the app alone cannot supply.

Suggested use:

- `demo_scenarios/`
  - reproducible profile + pantry + access setups for the live demo
  - start from `template_demo_scenario.md`
  - use `demo_run_of_show.md` for the main presentation sequence
- `metrics_package/`
  - before/after comparisons, timing, cost, and access-burden evidence
  - start from `template_metric_case.md`
  - use `judging_matrix.md` to tie cases back to DEBUT criteria
- `stakeholder_validation/`
  - pantry, clinic, community-health, and benefits-program feedback notes
  - start from `template_feedback_note.md`
- `user_interviews/`
  - scripts, participant summaries, task outcomes, and confusion points
  - start from `template_interview_script.md`
- `support_letters/`
  - letters from partners, faculty, clinics, or community organizations
  - start from `template_support_letter_outline.md`
  - use `support_letter_request_template.md` for outreach

Recommended order before submission:

1. Lock 3-5 demo scenarios that show pantry-first, emergency, SNAP/WIC-aware, and transportation-limited use.
2. Collect short stakeholder feedback on those exact scenarios.
3. Run quick user interviews with the same scenarios and log confusion points.
4. Build a small metrics packet showing why AccessPlate is better than a nutrition-first baseline.
5. Gather support letters that reference the problem setting and prototype relevance.
